🌐 My Personal Profile Page

This is my personal profile website built using HTML and CSS.  
It showcases my introduction, skills, and contact details in a simple and clean layout.


 🚀 Features

 🧑‍💻 Personal introduction with photo  
 💡 About Me section
  🧰 Skills section (HTML, CSS)  
📞 Contact details with links to GitHub & LinkedIn  

 🛠️ Technologies Used

HTML5
  CSS3

 📸 Preview

A simple profile layout with:
- A header section for the title  
- A profile image and name  
- About Me section in the center  
- Skills list  
- Footer with contact information  

🧭 How to Use

1. Clone or download this repository.  
2. Keep all files (HTML, CSS, images) in the same folder.  
3. Open the file `index.html` in your browser.  
4. You can customize the text, photo, and links as per your details.
